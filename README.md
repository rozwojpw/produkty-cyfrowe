# Produkty Cyfrowe

Skrypt `generate_dziennik.py` umożliwia wygenerowanie PDF-a z 7-dniowym dziennikiem praktyki Projekt **ARCHAIOS**.

## Jak użyć

1. Upewnij się, że masz zainstalowaną bibliotekę `reportlab` (`pip install reportlab`).
2. Uruchom skrypt:

```bash
python3 generate_dziennik.py
```

W katalogu pojawi się plik `dziennik_praktyki.pdf`.
